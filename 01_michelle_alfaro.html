<h2 id="3.-Gr%C3%A1ficos-en-escala-semilog">3. Gráficos en escala semilog¶</h2><p>La ecuación de Clausius-Clapeyron integrada,</p> <p>$$ \ln P = \ln P_{\text{ref}} - \frac{\Delta H_{\text{vap}}}{R}\left(\frac{1}{T} - \frac{1}{T_{\text{ref}}}\right), $$</p> <p>es lineal en $\ln P$ vs $1/T$. Por eso conviene graficar así para extraer $\Delta H$ experimentalmente.</p>

import numpy as np
import matplotlib.pyplot as plt
from utils.constantes import R, atm

n = 1.0
T = 350  # K
V = np.linspace(0.5, 5.0, 200)  # L

# Convertir V de L a m^3 para que sea consistente con R en J/(mol*K)
V_m3 = V / 1000
P = n * R * T / V_m3  # Pa

fig, ax = plt.subplots(figsize=(6, 4))
ax.plot(V, P / atm, lw=2, color="orange", label=f"T = {T} K")
ax.set_xlabel("V (L)")
ax.set_ylabel("P (atm)")
ax.set_title("Isoterma de un gas ideal (n = 1 mol, T = 350 K)")
ax.legend(frameon=False)
ax.grid(True, alpha=0.3)
fig.tight_layout()
plt.show()

import numpy as np
import matplotlib.pyplot as plt
from utils.constantes import R

Cv = 12.5         
Cp = Cv + R        
n = 1.0
T_ref = 300         

T = np.linspace(300, 1000, 200)
Cp_array = np.full_like(T, Cp)          
dS = n * Cp * np.log(T / T_ref)         # ΔS a presión constante

fig, ax1 = plt.subplots(figsize=(6, 4))

color1 = "tab:blue"
ax1.set_xlabel("T (K)")
ax1.set_ylabel("Cp (J/(mol·K))", color=color1)
ax1.plot(T, Cp_array, lw=2, color=color1, label="Cp")
ax1.tick_params(axis="y", labelcolor=color1)

ax2 = ax1.twinx()
color2 = "tab:red"
ax2.set_ylabel("ΔS (J/(mol·K))", color=color2)
ax2.plot(T, dS, lw=2, color=color2, label="ΔS")
ax2.tick_params(axis="y", labelcolor=color2)

ax1.set_title("Cp y ΔS vs T para un gas ideal")
fig.tight_layout()
plt.show()
