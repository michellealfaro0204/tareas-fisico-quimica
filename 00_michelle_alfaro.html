<h1 id="00-%C2%B7-Gu%C3%ADa-r%C3%A1pida-de-JupyterLab">00 · Guía rápida de JupyterLab¶</h1><p>Material de apoyo para la clase. Cubre lo mínimo necesario para trabajar con el resto de los cuadernillos.</p> <hr /> <h2 id="1.-%C2%BFQu%C3%A9-es-un-notebook?">1. ¿Qué es un notebook?¶</h2><p>Es un documento interactivo que mezcla:</p>
  • Celdas de código (Python) — se ejecutan con Shift + Enter.
  • Celdas de Markdown — texto con formato (títulos, ecuaciones LaTeX, imágenes, enlaces).
<p>El estado (variables, figuras, imports) se conserva entre celdas mientras el kernel esté vivo.</p>
<h2 id="2.-Atajos-esenciales">2. Atajos esenciales¶</h2> <thead> <th>Atajo</th> <th>Acción</th> </thead> <tbody> </tbody> <tbody></tbody>
Shift + Enter Ejecutar celda y pasar a la siguiente
Ctrl + Enter Ejecutar celda y quedarse
A / B Insertar celda arriba / abajo
M / Y Convertir a Markdown / Código
D D Borrar celda
Z Deshacer borrado

<h2 id="3.-Markdown-+-LaTeX">3. Markdown + LaTeX¶</h2><p>Las celdas Markdown aceptan sintaxis estándar y ecuaciones en LaTeX entre $$ ... $$:</p> <p>$$ \Delta U = q + w \qquad \Delta H = \Delta U + \Delta (PV) $$</p> <p>Útil para escribir la ecuación de Clausius-Clapeyron, la definición de entropía, etc.</p>
<h2 id="4.-Comandos-magic-y-shell">4. Comandos magic y shell¶</h2><p>Los magics son instrucciones especiales de Jupyter. Las más usadas:</p>
  • %time mide el tiempo de una línea.
  • %matplotlib inline muestra las figuras de Matplotlib dentro del notebook.
  • ! ejecuta un comando de shell (por ejemplo !pip install ...).
